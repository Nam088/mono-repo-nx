# English Docs And Comments

- Write all new technical documentation in English (README updates, inline docs, architecture notes, migration guides, API usage docs).
- Write all new code comments in English (JSDoc, block comments, inline comments, TODO notes).
- Keep existing non-English text unchanged unless the task explicitly asks to translate it.
- If a user explicitly requests another language for a specific output, follow the user request for that output only.
- Prefer concise, clear technical English over verbose prose.
